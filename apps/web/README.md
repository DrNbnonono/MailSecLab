# MailTrace Web 0.5

Next.js App Router、React、TypeScript、Tailwind CSS 与 React Flow 构成邮件头调查工作台。单封分析输入与报告只存在当前页面内存中；研究工作台由后端自动归档原始邮件与产物。网页不写入 localStorage。

先启动 [API](../api/README.md)。在本目录运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 `http://127.0.0.1:3000`。生产模式运行 `npm.cmd run build`，再运行 `npm.cmd run start`。默认仅监听 `127.0.0.1`。Node.js 要求 22+，实际验证为 22.22.2，依赖由 `package-lock.json` 固定。

## 使用

1. 粘贴原始邮件/邮件头，或点击/拖入 `.eml` 文件。合成样本按钮只填入内容，点击分析后才调用 API。
2. 在链路图或时间线中选择声明；右侧证据展示原始字段、行号、字节范围、时间与协议。中继节点上的两个字段按钮分别定位接收与来源声明。
3. 在认证、异常与邮件头标签中查看声明、调查提示和可搜索的折叠原文。证据链接均定位具体字段。
4. 下载完整 JSON 以核查头区 Base64 和全部链路。文件名仅使用输入哈希前缀。

编辑输入会标记旧报告；清空、替换文件或改动内容会取消待完成请求，旧请求不会覆盖新输入。服务错误显示在输入区。

## 研究工作台

从顶部“研究工作台”进入 `/lab`，或直接打开 `http://127.0.0.1:3000/lab`。

- **样本生成**：设置固定时间、种子、Received 与尺寸参数；高级设置提供有序字段 JSON 和重复 From/Message-ID 快捷操作。单变量扫描每次覆盖一个轴。生成后显示每份请求参数、实测指标与分析入口。
- **逐跳对比**：选择或拖入 `.eml`，用上下按钮明确排序并填写标签、采集位置和可选 MTA 信息。勾选与前一采集之间的缺口。区间选择只包含相邻快照；两侧证据分别选择候选字段，显示原文、字节范围与哈希。
- **实验历史**：读取后端本地归档，每页 50 项，可刷新、重开、核验复现和导出。复现产生新 ID，保留来源关联。缺失或哈希损坏明确提示，不能继续下载或复现。

研究页明确提示**自动保存原始实验邮件（包括正文）**。点击“取消等待”只取消页面等待；后台可能已开始归档，请刷新历史。生成组不表示传输链；差分结论不自动确定修改者，原有安全规则在快照分析中独立显示调查提示。

字段变化及左右候选列表每页 50 项，避免重复字段一次渲染大量按钮。手机上输入与证据纵向排列，指标表在容器内水平滚动，全文档保持适配。完整 ZIP、CSV、清单、原始邮件链接指向已保存的独立实验。

图中显示前 100 跳，并提示省略数量；时间线与邮件头每页 50 条；单字段预览最多 65,536 字符。完整 JSON 不受这些展示限制。已知连续中继可合并，未知与断开的节点保持独立；回返节点按出现次数显示，不会被合成唯一节点。

## 代理配置

浏览器仅访问同源 `POST /api/analyze`。Next.js 在服务器端代理固定后端路径：JSON → `/api/v1/analyze`，multipart → `/api/v1/analyze/file`。文件内容以字节流转发，不做文本重编码。

后端默认 `http://127.0.0.1:8000`。需要调整时复制 `.env.example` 为 `.env.local` 并修改 `MAILTRACE_API_URL`，重启服务。该变量不暴露给浏览器。代理请求体限制 12 MiB，上游超时 45 秒；响应不缓存，不在错误中回显输入。

研究操作通过同源 `/api/lab/...` 代理到固定允许的 `/api/v1/lab/...` 路径。原始上传字节和 ZIP/CSV 下载保持二进制转发。研究请求单独限制 52 MiB，超时 120 秒；每封/累计/数量限制由后端和页面共同提示。归档根目录由后端 `MAILTRACE_EXPERIMENT_DIR` 控制，不通过浏览器设置。
