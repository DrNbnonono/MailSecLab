| 场景 | 实际结果 |
| --- | --- |

| 快照分析 | 200 跳报告完整；图展示上限保持原工作台规则，证据定位可用 |
| ZIP / CSV | 浏览器下载成功，ZIP 清单及 12 个产物逐项核验 SHA-256 |
| 核验复现 | 新 ID 与 derived_from 正确，所有样本哈希与来源一致 |
| 历史重开 | 读取原实验，4 个快照及参数保持；服务重启后仍可重开 |
| 三份采集快照 | 先按错序选择，再用下移按钮恢复 01→02→03；提交顺序、标签和 MTA 标签保持 |
| 相邻证据 | 首区间新增顶端 Received、Subject 折行、重复组数量变化；双侧原文保留 CRLF 与字段各自 ID/字节范围/哈希 |

成功工作流未产生 JavaScript pageerror。不可实现参数和损坏文件会产生预期 HTTP 422/409 网络错误记录。取消等待测试通过代理延迟已完成响应实现，不声称能撤销服务端写入。

CLI 手工运行交付语料，数量扫描为 0/50/51/200，最长行扫描为 997/998/999，头区扫描为 1024/4096/8192；重复与畸形用例成功归档。逐跳合成语料 CLI 归档原始字节与输入文件一致。

浏览器截图、下载、验收脚本与合成运行结果保存在 Git 忽略的 `output/playwright/`、`.playwright-cli/` 和 `local-experiments/`。交付的参数与采集语料位于 `experiments/`，仅使用合成地址/正文。未发送任何邮件，未运行 MTA，不据此推断实际传输极限。

## 审查与修复

独立只读审查识别并修复：数量扫描改变旧跳 ID、无名畸形行被强配对、Received 变化查找二次复杂度、写入/读取清单额度不一致、双侧大量候选未分页。补充回归后复核无阻塞交付问题；6000 跳 CRLF→LF 差分在审查环境约 0.951 秒，作为单次观测，不作为通用性能承诺。

哈希核验是本地完整性检查，不是签名。当前归档采用本机目录，未实现账户、数据库索引或多人部署；真实传输采集与极限测量属于下一轮 RelayLab / LimitProbe。
